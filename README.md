## Приложение «Личный финансовый помощник»

Небольшое учебное веб‑приложение, которое позволяет вести несколько бюджетных «кошельков», фиксировать по ним доходы и расходы и быстро получать сводку по каждому счёту.

### Как запустить проект

1. **Установка зависимостей**

```bash
npm install
```

2. **Сборка TypeScript‑кода**

```bash
npm run build
```

3. **Просмотр в браузере**

- вариант 1: поднять простой локальный сервер

```bash
npm run serve
```

- вариант 2: открыть файл `index.html` напрямую в браузере (после сборки).

### Основные возможности

- **Работа с несколькими счетами**: создание новых и удаление ненужных.
- **Детальная панель по счёту**: текущий баланс, суммарные доходы и расходы.
- **Операции с транзакциями**: добавление и удаление записей о доходах/расходах.
- **Выгрузка данных**: экспорт списка транзакций выбранного счёта в CSV‑файл.
- **Простой интерфейс**: переключение между списком счетов и деталями одного счёта.
